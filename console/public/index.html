Upload a list

CSV or Excel, any column names
Used for every row, unless a row has its own Product column naming one of the two known products — an unrecognised value in that column refuses just that row rather than guessing.
Column names do not need to match anything — email, first name, last name, company, title, website and phone are recognised under about sixty common spellings each.
Up to 300 rows per file, 10MB. A larger list splits into more than one upload.

A 500-row file is not 500 emails. Every row goes through the same product refusal, suppression check and duplicate check as a single typed lead. Rows that cannot be used come back listed with the reason, so you fix those rows rather than the whole file.
